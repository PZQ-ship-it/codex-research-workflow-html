科研项目骨架 skills

Skill触发场景
research-fact-source-sync实验事实、指标、术语变化后，需要同步论文正文、图表和证据边界。
research-experiment-design-reviewer训练设计、实验设计、ablation、benchmark/eval 或统计分析计划在开跑前需要审查 claim-evidence、baseline、公平性、泄漏、统计和复现风险。
resilient-llm-benchmark多模型、多样本、多模式 LLM 跑批，需要断点续传、重试、分片和日志。

latex-pdf-final-reviewLaTeX 论文提交前做 PDF 级终稿审阅。
html-research-notes用 HTML 而不是 Markdown 创建结构化科研笔记或模板。
paper-pdf-to-structured-html把论文 PDF 转成结构化高可读 HTML，按综述、算法、benchmark 或系统论文区别处理，并筛入关键图表。
google-scholar-profile-intel按具体需求路由 Google Scholar 学者主页抓取、OpenAlex 补全、Apify 输入和深度引用爬取，不使用 SerpApi。
hkust-gz-faculty-intel按港科广 Hub 和一个或多个 Thrust 抓取公开教师主页数据，导出规范化 JSON/CSV。
zhihu-public-intel面向公开知乎内容检索、问题/回答/文章/评论抓取与规范化整合，不以个人收藏或历史为主线。
early-signal-intel面向 alphaXiv、Hacker News、RSS/lab blog、Bluesky、Reddit 等早期讨论信号做路由、轻量抓取、规范化和安全 API 配置闭环。
chinese-ai-signal-crawler面向机器之心、量子位、PaperWeekly、新智元、AI科技评论、微信公众号和 B站等中文 AI 二次传播信号做抓取、归一化和私有配置闭环。
ai-lab-blog-intel面向 OpenAI、Anthropic、DeepMind、Google Research、Meta AI、Microsoft Research、NVIDIA、Apple ML、Ai2 等公司/实验室研究博客做 RSS、sitemap、HTML 抓取、归一化和可选 API 配置闭环。
openrouter-icu-image通过 OpenRouter ICU 同步生成或编辑图片，保存最终图片文件到项目目录。

第三方学术研究 skills

这些 skill 用于从教授画像、研究构思、proposal 写作到投稿前自查的学术准备流程。来源与固定 commit 记录见 skills/THIRD_PARTY_SKILLS.md。

Skill触发场景
academic-research-suiteCodex-native 学术研究套件，适合 research question refinement、literature review、proposal/paper planning、paper review 和端到端 academic pipeline。
professor-fit-analyzer针对具体教授或实验室做公开证据 dossier、研究 taxonomy、future directions、申请者 fit、warning signs、套磁邮件和面谈策略。
research-proposal博士申请或套磁材料需要生成 2,000-4,000 词 research proposal / research plan，并按 STEM、人文、社科区分结构。
idea-evaluator对初步 research idea 做 novelty、feasibility、fatal flaws、能力匹配和 reviewer-style verdict 评估。
vibe-research-workflow把 AI 辅助科研拆成 coding、figure、writing 等阶段，适合从 loose idea 推进到可执行研究流。
intro-drafter基于 Introduction flowchart，把研究动机、gap 和贡献链条整理成 intro 大纲。
tech-paper-template技术类 full paper 的完整逻辑链、结构骨架和一致性检查。
benchmark-paper-templateBenchmark / evaluation 类论文的评价维度、数据构建、实验设计和论文结构。
pre-submission-reviewer投稿或发送材料前，从顶会审稿人视角检查逻辑、结构、LaTeX、语法和高风险表达。
figure-designer为论文或 proposal 设计动机图、方法总览图和实验结果图的视觉表达方案。
