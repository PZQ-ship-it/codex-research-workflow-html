# Benchmark Discovery

Use this reference when building `benchmarks/sources.md`.

## Source Selection

Prefer:

- official benchmark sites or papers;
- university writing centers, teaching centers, fellowship offices, and faculty affairs pages;
- standards, rubrics, policy pages, or provider documentation;
- peer-reviewed or primary-source material when the skill domain is academic, medical, legal, financial, or safety-sensitive.

Avoid using generic template sites as primary evidence unless no better source exists.

## AnySearch Closure

When live source discovery is needed, use `$anysearch`.

1. Run the local `doc` command first if not already done in this session.
2. Use anonymous access unless the user explicitly sets up an API key.
3. Do not query or extract sensitive personal information, secrets, passwords, tokens, private documents, or proprietary data.
4. Record only source URLs, titles, short relevance notes, and derived rubric dimensions.
5. If AnySearch extraction fails, record the failure and either exclude the source or use search snippets only with low confidence.

## `benchmarks/sources.md` Contents

Include:

- provider and access mode;
- source table with IDs such as `S1`, `S2`;
- URL and title for each source;
- how each source maps to product-quality dimensions;
- excluded sources and why;
- derived rubric dimensions.

Do not paste large raw source dumps into the benchmark file. Summarize the useful criteria.
