Native Autoresearch Goal Checklist

  • Mission artifact defines objective, scope, non-goals, and deliverable.
  • Rubric artifact defines professor/critic pass-fail criteria.
  • Ledger records source batches, attempts, failures, and verdicts.
  • Codex goal is created only when explicitly appropriate.
  • Critic verdict is pass before completion.
  • Completion artifact records status, deliverable path, evidence, and residual risk.
  • update_goal complete is called only after the completion audit passes.
