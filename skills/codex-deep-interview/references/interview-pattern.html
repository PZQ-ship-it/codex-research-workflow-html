Deep Interview Pattern

Use this reference when a request needs clarification before planning or execution.

Unknowns Pass

  • Read obvious local context before asking: AGENTS, README, task cards, design docs, source files.
  • Classify gaps as discoverable facts, human preferences, or dangerous assumptions.
  • Ask for a prompt-safe summary first when the supplied context is too large.

Depth Profiles

  • Quick: low-risk ambiguity, usually no more than 5 rounds.
  • Standard: default requirements interview, usually no more than 12 rounds.
  • Deep: high-risk or branching work, usually no more than 20 rounds.

Question Style

  • Ask one question at a time.
  • Ask only questions that change scope, risk, design, or acceptance.
  • Prefer concrete options with tradeoffs over open-ended prompts.
  • Do not ask for facts that can be discovered from the repo or official docs.
  • Use concrete scenarios to expose decision boundaries and hidden assumptions.

Readiness Gates

  • Goal, scope, and acceptance criteria are executable.
  • Non-goals are explicit.
  • Decision boundaries are explicit.
  • Residual risk is named and acceptable for the next lane.
