Code Review Checklist

Categories

  • Correctness: wrong behavior, regressions, edge cases, error paths.
  • Security: secrets, injection, authz/authn, unsafe parsing, XSS/CSRF.
  • Performance: N+1, avoidable O(n^2), excessive rerenders, caching mistakes.
  • Maintainability: duplication, coupling, unclear boundaries, weak naming.
  • Tests: missing critical-path coverage, brittle tests, untested migrations.

Verdict

  • REQUEST CHANGES: critical/high issue, architect block, or missing required review evidence.
  • COMMENT: non-blocking medium/low issues or architect watchlist.
  • APPROVE: no blocking findings and residual risks are acceptable.
