AI Slop Cleanup Checklist

  • Behavior is locked with tests, smoke checks, or visual evidence.
  • Scope is explicit and does not include unrelated dirty work.
  • Fallback-like code is classified before changing it.
  • One smell category is cleaned per pass.
  • No speculative abstraction or new dependency is added without need.
  • Verification is rerun after cleanup.
  • Final report names simplifications, changed files, checks, and residual risks.
