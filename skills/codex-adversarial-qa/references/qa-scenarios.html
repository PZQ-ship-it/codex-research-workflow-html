Adversarial QA Scenarios

Each matrix row should include id, actor, setup, expected signal, actual result, evidence, fix, and cleanup status.

  • Code: empty input, duplicate input, stale cache, partial failure, retry path, concurrent run, misleading success output, hung command.
  • Paper: inconsistent term, unsupported claim, metric name drift, figure/table mismatch, missing citation.
  • Figure: missing category, long label, font fallback, color collision, mobile/export scaling.
  • Benchmark: API timeout, malformed response, interrupted shard, model switch, cost boundary.
  • Prompt: ambiguous role, hidden assumption, over-broad scope, no evidence requirement, prompt injection, instruction conflict.
  • Workflow: dirty worktree, stale state, cancel/resume, missing cleanup, repeated run idempotency.
  • UI: mobile width, broken image, console error, clipped text, inaccessible control, stale screenshot.
