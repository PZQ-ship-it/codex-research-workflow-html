# Legacy Quick Review Template

Use this template only when the user explicitly asks for a separate `quick_review.md` export.

By default, quick recall content must be integrated into `paper.html` under a section such as `快速复习卡片`.

```markdown
# 快速复习：<Paper Title>

## 30 秒回忆
- 这篇论文研究的是：
- 核心想法是：
- 主要证据是：
- 最大局限是：
- 我会向导师提到它，因为：

## 核心概念
| 概念 | 一句话解释 | 为什么重要 | 常见误解 |
|---|---|---|---|

## 自测问题
1. 这篇论文解决了什么问题？
2. 它的核心机制是什么？
3. 哪个结果或图表最值得记住？
4. 最强的局限是什么？
5. 它如何连接到我的目标导师或 PhD 方向？
```
