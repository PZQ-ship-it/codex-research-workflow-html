# Validation

Use this reference before claiming a tree build, extension, or maintenance run is done.

## Useful Tree Gate

Do not call a tree useful until it has:

- an index with a clear reading order;
- a source manifest;
- a visible branch structure, either in `index.md` for compact trees or in `branches/` for mature trees;
- at least one card per major layer;
- explicit uncertainty labels;
- human-facing prose follows the requested language, default Chinese;
- comparisons between major alternatives;
- at least one research hook;
- at least one learning guide;
- a build ledger;
- a validation check.

## Mature Tree Gate

Do not call a tree mature until it has:

- branch files with role, questions, nodes, evidence, gaps, expansion rules, and next steps;
- status files for downloaded and extracted evidence when local evidence is used;
- research lanes or opportunity tracking;
- review-ready matrices for the most promising hooks;
- protocol drafts for selected implementation lanes;
- validation covering links, counts, uncertainty labels, protocols, and secret-like strings.

## Experiment-Ready Gate

Do not call an experiment ready until it has:

- falsifiable hypothesis;
- baseline;
- isolated modification;
- ablations;
- primary metric;
- guardrail metric;
- failure interpretation;
- reviewer-risk checklist;
- review handoff;
- benchmark, data, version, and license checks where relevant.

## Frontier-Actionable Gate

Do not call a frontier opportunity actionable until it has:

- evidence strength;
- first minimal test;
- branch or frontier-lane owner;
- risk and invalidation condition;
- next action.

## Minimal Static Checks

Run or implement checks for:

- required files;
- broken relative Markdown links;
- suspicious secret-like strings;
- local absolute paths in public notes;
- source/status file consistency;
- expected card counts;
- branch file required sections;
- uncertainty labels;
- language compliance for human-facing prose;
- protocol coverage when protocols exist;
- frontier coverage when frontier exists.
