# Intake Questionnaire

Use this when the user asks for strategy, fit, admissions chances, school lists, or a first draft and has not provided enough context. Ask only what is necessary for the task.

## Minimal Intake For Drafting

- Target degree type: MA, MPhil, PhD, MDiv, STM, ThM, MFA, JD/PhD, etc.
- Target program and school, if known
- Discipline or subfield
- Application prompt and word limit
- Applicant background or CV
- Research interests or intellectual goals
- Relevant coursework, research, thesis, writing sample, or major papers
- Post-graduation goals

## Full Intake For Strategy

- GPA and grading scale
- Transcript or list of coursework
- CV
- Citizenship, residency, or nationality only when relevant to international status, tuition, visa, funding, or language requirements
- Language test scores, if relevant
- Current and past academic interests
- Future research direction
- Target degree type
- Target schools and academic programs
- Preferred faculty advisors
- Publications, conference papers, writing samples, thesis, or major papers
- Research, teaching, professional, ministry, artistic, legal, public-facing, or other relevant experience
- Post-graduation goals
- Funding constraints and financial pressure
- Application deadlines
- Existing drafts
- Application prompts and word limits

## Lightweight Intake For Narrow Tasks

If the user asks only for polishing, compression, or line editing:

- Work with the available draft.
- Ask for the prompt, word limit, target program, and discipline only if needed.
- State briefly what missing context would make the revision stronger.

## Chinese Intake Template

请先提供这些信息中与你当前问题相关的部分：

- 申请的学位类型和专业方向
- 目标学校/项目，若已有
- 申请材料类型和字数限制
- 你的教育背景、GPA、主要课程
- 研究兴趣、已有论文/课程论文/毕业论文/写作样本
- 相关研究、教学、工作、实践或公共写作经历
- 想匹配的导师
- 毕业后的目标
- 资金压力、身份/签证/语言成绩等相关情况
- 现有草稿和申请 prompt
