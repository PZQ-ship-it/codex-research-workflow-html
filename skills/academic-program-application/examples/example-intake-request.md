# Example Intake Request

User:

我想申请北美的宗教学 PhD，但现在只有一个很粗的方向：现代中国基督教史。你能帮我规划申请吗？

Assistant:

可以。这个问题属于完整申请策略，所以我需要先做一个简洁 intake。你可以先回答你方便回答的部分：

- 目标学位：是否只考虑 PhD，还是也考虑 MA/MTS/STM 作为过渡？
- 教育背景：本科/硕士学校、专业、GPA 或成绩区间
- 课程准备：宗教学、历史学、神学、中文/英文史料、方法论相关课程
- 研究经历：毕业论文、课程论文、会议、发表、档案或田野经验
- 语言能力：英文考试、中文史料能力、是否有其他研究语言
- 初步研究问题：你对现代中国基督教史的哪一段、哪类群体、哪种材料感兴趣？
- 写作样本：有无英文或中文 academic paper，可以改成申请用 writing sample 吗？
- 资金压力和身份：是否需要全奖，是否是国际申请者？
- 时间线：申请哪一年度入学，截止日期大概什么时候？

如果你愿意，也可以直接贴 CV 或一版自我介绍。我会先帮你判断应该申请哪些类型的项目，再做学校列表和材料策略。
