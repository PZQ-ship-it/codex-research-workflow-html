Performance Evidence Checklist

  • Metric and pass/fail threshold are explicit.
  • Baseline was captured before edits.
  • Evaluator command or measurement protocol is reproducible.
  • Noise controls, sample count, and environment are recorded when relevant.
  • Each optimization is measured independently when practical.
  • Regression tests or correctness checks still pass.
  • Final report includes before/after values and kept/reverted decisions.
